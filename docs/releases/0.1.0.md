# Ritua 0.1.0

First local release — 2026-09-08. macOS, Apple Silicon (arm64).

## Included

- Task, Area and Project workflows with local SQLite persistence.
- Work and Personal as the only default Areas, with an empty first workspace.
- Calendar scheduling, task resizing, recurring tasks and Undo.
- Daily and weekly planning, canonical weekly-review task identity.
- Attachments, workspace backups, restore and interrupted-save recovery.
- Ritua application branding and a macOS DMG installer.

## Install

Open `Ritua-0.1.0-arm64.dmg` and drag Ritua into Applications. The ZIP contains the same app.
This local release is unsigned and not notarized. There is no configured automatic-update
channel or public publication. Application data is stored outside the app bundle.

## Verified

The packaged app passed the native regression suite in disposable profiles, including
fresh initialization, create/edit/complete/Undo, scheduling, calendar resize and cancellation,
recurrence, attachments, backup/recovery, close-save and restart persistence. The DMG checksum
and ZIP archive integrity were verified. Type checking and architecture checks passed.

## Known limits

- Drag-and-drop flows between lists, Projects and the calendar have not been fully reverified
  for this release; the native pointer regression covers calendar task resizing and cancellation.
- Settings UI is intentionally absent pending redesign, including archive/profile/update controls.
- Signed distribution, notarization and end-to-end automatic-update delivery are not configured.

This is the initial release baseline; there is no historical database import or migration path.
