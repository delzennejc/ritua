# Ritua 0.1.6

Local patch release — 2026-09-25. macOS, Apple Silicon (arm64).

## Included

- Create tasks directly in the calendar with explicit scheduling ranges.
- Today workflow statuses and board interactions.
- Task context menu actions for moving dates and deleting tasks.
- Improved window sizing and task context menu appearance and positioning.
- Preserve calendar dates when carrying over missed tasks.

## Install

Open `Ritua-0.1.6-arm64.dmg` and drag Ritua into Applications. Quit Ritua
before replacing its bundle. Workspace data remains outside the app bundle.

This local release is unsigned and not notarized. No automatic-update channel
or public publication is configured.
