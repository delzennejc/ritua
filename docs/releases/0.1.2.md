# Ritua 0.1.2

Local patch release — 2026-09-10. macOS, Apple Silicon (arm64).

## Included

- Completing a calendar task within ±3 hours of its planned end adjusts the block to
  the completion minute and shifts later unfinished tasks on the same day. Their durations
  and gaps are preserved, with shifts capped at midnight. The rule applies consistently
  across task details, boards, planning views and project task controls.
- Paste or drop images into Task details to build a media library below the notes.
  Images can be previewed, copied and removed, and are preserved in saves and backups.
- Improved task and subtask drag-and-drop, calendar scrolling during drags, and board
  scrolling that stays on one axis during a gesture.

## Install

Open `Ritua-0.1.2-arm64.dmg` and drag Ritua into Applications. The ZIP contains the same app.
Quit Ritua before replacing the application. Application data is stored outside the app bundle.
This local release is unsigned and not notarized, with no configured automatic-update channel
or public publication.
