# Ritua 0.1.3

Local release — 2026-09-14. macOS, Apple Silicon (arm64).

## Included

- Calendar Sessions group canonical tasks, with checklist completion, reordering,
  drag-out, resizing and deletion Undo.
- Improved calendar drag previews and timeline layout.
- A reorganized application and domain layer: task commands update canonical
  documents, and boards, projects and calendars derive their task data from them.
- Edits reuse unchanged records, with less repeated validation and projection work.
- Recovery checkpoints are serialized and deduplicated, with failed writes retried.
- Clearer navigation, shared task actions and panel component boundaries.

## Install

Open `Ritua-0.1.3-arm64.dmg` and drag Ritua into Applications. The ZIP contains the same app.
Quit Ritua before replacing the application. Workspace data stays in Application Support,
outside the app bundle. This release does not change the database schema.

This local release is unsigned and not notarized. No automatic-update channel or public
publication is configured.
