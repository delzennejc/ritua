# Ritua 0.1.1

Local patch release — 2026-09-09. macOS, Apple Silicon (arm64).

## Included

- Refined Area selectors, Project icons and task creation animation.
- Updated application icon artwork and Ritua branding, with the finalized bird positioning.
- Shared dropdowns for detail action menus and more consistent menu behavior.

## Install

Open `Ritua-0.1.1-arm64.dmg` and drag Ritua into Applications. The ZIP contains the same app.
Quit Ritua before replacing the application. Application data is stored outside the app bundle.
This local release is unsigned and not notarized, with no configured automatic-update channel
or public publication.

## Verified

- Production build, architecture checks and TypeScript checks passed.
- `npm test` passed, including native persistence, recovery, IPC and close-save checks.
- The packaged application passed the same regression suite in disposable profiles.
- Packaged application version is `0.1.1`.
- DMG checksum and ZIP archive integrity checks passed; SHA-256 checksums accompany the artifacts.
- Git whitespace checks passed.

## Known limits

- Full manual visual and drag-and-drop verification was not repeated for this release.
- Settings UI remains intentionally absent pending redesign.
- Signed distribution, notarization and end-to-end automatic-update delivery are not configured.
